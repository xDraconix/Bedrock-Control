# Bedrock Control PRO v2.8.0 – Live-Monitoring

## Neue Funktionen

### Historisches Live-Monitoring

- CPU-Auslastung des Minecraft-Dienstes
- RAM-Verbrauch des Minecraft-Dienstes
- Anzahl der Online-Spieler
- Historische Diagramme für 1h, 6h, 24h, 7d und 30d
- Automatische Messungen im 60-Sekunden-Intervall
- Lokale Speicherung in einer geschützten SQLite-Datenbank
- Automatische Bereinigung von Messdaten nach 30 Tagen

### Verbesserte Diagramme

- Synchronisierte Zeitachsen
- Interaktive Tooltips
- Anzeige von Minimum, Durchschnitt und Maximum
- Unterstützung der Tastaturbedienung
- Visuelle Interpolation einzelner fehlender Messpunkte
- Fehlende Messwerte werden nicht als Null gespeichert
- Gespeicherte Messwerte und Statistiken bleiben unverändert

### Systemintegration

Neue Komponenten:

- bedrock-monitor-manager
- bedrock-monitor.service
- bedrock-monitor.timer

Der Monitoring-Timer arbeitet unabhängig vom Browser.

## Installation und Upgrade

Für bestehende Installationen gilt:

v2.7.1 -> v2.7.2 -> v2.8.0

Die Version v2.7.2 ist eine notwendige Update-Brücke.
Sie erweitert die sichere System-Allowlist um die
Monitoring-Komponenten.

Ein direktes Upgrade von v2.7.1 auf v2.8.0
wird nicht unterstützt.

Die Installation erfolgt über den signierten
Update-Mechanismus mit Ed25519-Prüfung.

## Sicherheit

- Signierte Release-Dateien
- Streng begrenzte Systemkomponenten-Allowlist
- Prüfung der Systemkomponenten vor Installation
- Interne Snapshots und Rollback-Mechanismus
- Monitoring-Timer-Aktivierung nach Funktionstests
- Keine beabsichtigten Änderungen an Minecraft-Welten
- Keine beabsichtigten Änderungen an Add-ons

## Teststatus

Erfolgreich geprüft:

- Automatische Python- und JavaScript-Tests
- GitHub-CI
- Signiertes Upgrade von v2.7.1 auf v2.7.2
- Signiertes Upgrade von v2.7.2 auf v2.8.0
- Monitoring-Funktionen auf Minecraft-Test-2
- Simulierte Installations- und Rollback-Fehler

Noch nicht vollständig durch Integrationstests nachgewiesen:

- Erstinstallation ohne vorhandene Monitoring-Komponenten
- Realer End-to-End-Fehler-Rollback auf dem Testcontainer

Der verwendete Testcontainer enthielt bereits
manuell installierte Monitoring-Komponenten.

## Hinweise

Vor dem Upgrade ein vollständiges Systembackup erstellen.
Minecraft und Monitoring nach dem Update kontrollieren.

Die bisherige Monitoring-Datenbank soll erhalten bleiben.
