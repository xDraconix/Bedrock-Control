# Bedrock Control PRO v2.5.5 – Stable

## Neu

- **Weltseed anzeigen:** Der Welten-Manager liest den Seed aus der Bedrock-Datei `level.dat` (`RandomSeed` im Little-Endian-NBT) und zeigt ihn direkt unter der Welt an.
- **Ein-Klick-Kopieren:** Der Button übernimmt den Seed direkt in die Zwischenablage – auch bei Zugriff über `http://SERVER-IP:8088`, soweit der Browser dies unterstützt. Wird Kopieren blockiert, zeigt das Panel eine Hinweismeldung statt eines aufdringlichen Kopierdialogs.
- **Weitere Weltinformationen:** Spielmodus, Schwierigkeitsgrad und Weltname aus `level.dat` werden angezeigt, sofern vorhanden.
- **Sichere Verarbeitung:** Weltdateien werden ausschließlich lesend geöffnet; Beschädigungen oder nicht unterstützte Formate führen zu „Nicht verfügbar“. Negative Seeds und 64-Bit-Grenzwerte werden als Dezimaltext behandelt, ohne JavaScript-Präzisionsverlust.

## Update von 2.5.4 (oder früher)

**Wichtig: Dieses Release ändert `/usr/local/sbin/bedrock-world-manager`.**
Der bisherige signierte Web-Updater aktualisiert **nur die Webpanel-Dateien**, nicht die Root-Hilfsprogramme. Daher die vollständige Version **über den Installer installieren**, beispielsweise aus dem GitHub-Release-Asset `Bedrock-Control-PRO-v2.5.5-Release.zip`:

```bash
unzip Bedrock-Control-PRO-v2.5.5-Release.zip
cd bedrock-control-pro-2.5.5-installer
bash install.sh
```

Den Release-Installer mit einem sicheren Download beziehen und die veröffentlichte Ed25519-Signatur sowie SHA-256 anhand des bereits vertrauenswürdigen öffentlichen Schlüssels prüfen. Nicht blind ein Source-Archiv oder eine unbestätigte Quelle ausführen. Vor produktiven Änderungen einen Proxmox-Snapshot bzw. Backups erstellen.

Der Installer führt keinen beabsichtigten Neustart des Minecraft-Dienstes aus; vorhandene Weltdateien bleiben erhalten. Anschließend Panel neu laden (Strg+F5).

## Verifikation

```bash
cat /opt/bedrock-control-pro/VERSION
/usr/local/sbin/bedrock-world-manager list
systemctl is-active mcbedrock.service
```

Erwartet: `2.5.5`, Weltauflistung mit `seed` (als Zeichenkette, falls lesbar) und weiterhin aktiver Minecraft-Dienst.

- `Bedrock-Control-PRO-v2.5.5-Release.zip.manifest`

Das **private** Ed25519-Schlüsselpaar bleibt ausschließlich auf dem vertrauenswürdigen Signierrechner; die privaten Schlüsseldateien dürfen nicht in GitHub, das Release-ZIP oder auf den Minecraft-Server gelangen.
