# Test-Release v2.5.3 – Web-Updater-End-to-End-Test

**Testversion, nicht für produktive Server.**

## Zweck

Erster vollständiger Download-und-Installationsversuch über den **Panel-Update-Button** der installierten Version `2.5.2-beta7`.

## Neuerungen im Testpaket

- Die Weboberfläche meldet die Version `2.5.3`.
- Der Root-Hintergrunddienst aus Beta 7 wird wiederverwendet.
- Das signierte Update ersetzt ausschließlich `public/`, `set-password.php` und `VERSION`. Es führt **nicht** das mitgelieferte `install.sh` aus.
- Minecraft-Dateien, Welten und Minecraft-Dienst bleiben unverändert. Apache wird zur Prüfung neu gestartet.
- Ein Backup wird vor dem Dateiaustausch angelegt; erkannte Fehler lösen einen Rollback aus.

## Vorgeschriebene GitHub Assets

- `Bedrock-Control-PRO-v2.5.3-Release.zip`
- `Bedrock-Control-PRO-v2.5.3-Release.zip.manifest`
- `Bedrock-Control-PRO-v2.5.3-Release.zip.manifest.sig`

Das Manifest muss auf einem **anderen, vertrauenswürdigen Rechner** mit dem privaten Ed25519-Herausgeberschlüssel signiert werden. GitHub stellt die Signatur **nicht** automatisch her. Der private Schlüssel bleibt offline und darf weder ins Repository noch auf einen Minecraft-Server.

## Testverfahren

1. Beta 7 auf dem Testcontainer installieren und Proxmox-Snapshot anlegen.
2. Testpaket signieren, die drei Dateien als GitHub Release v2.5.3 veröffentlichen.
3. Unter „Panel-Updates“ GitHub prüfen, Signaturassets und Update-Button kontrollieren.
4. Update nach Anmeldung bestätigen, Fortschrittsprotokoll beobachten.
5. Prüfen: `cat /opt/bedrock-control-pro/VERSION`, `systemctl is-active apache2 mcbedrock.service` und `journalctl -u bedrock-panel-self-update.service -n 100 --no-pager`.
6. Bei Fehlern zuerst Logs und Snapshot sichern, bevor weitere Updates versucht werden.

**Wichtig:** Der Quellcode auf `main` repräsentiert noch nicht zwangsläufig die veröffentlichte v2.5.3-Paketfassung. Vor einer dauerhaften offiziellen Veröffentlichung den Quellcode synchronisieren und Tag/Release passend zum entsprechenden Commit setzen.

## Prüfergebnisse vor Veröffentlichung

ZIP-Integrität, Python/PHP/Bash/JavaScript-Syntax sowie Ed25519-Verifikation mit temporärem Testschlüssel und Zurückweisung einer manipulierten Datei wurden isoliert geprüft. Eine echte Signatur mit dem Herausgeberschlüssel und ein Debian-13-Web-Update sind noch nicht ausgeführt.
