# DracoRock Control v3.0.0 – Design Preview

**Status:** Entwicklung / kein Stable-Release

## Neue visuelle Identität

- Eigenständiges, selbst enthaltenes SVG-Markenlogo: ein facettierter Felsenkern mit leuchtendem Kontrollkern und einer abstrahierten Drachenkante.
- Vereinheitlichtes Dunkelblau-/Petrol-Farbsystem mit mintgrünen Akzenten.
- Neu gestaltete Login-Karte, Sidebar, Navigation, Dashboard-Karten, Statusanzeigen und Aktionsbuttons.
- Mobile Anpassung bis zu schmalen Displays, sichtbare Tastatur-Fokusmarkierungen und Unterstützung für reduzierte Animationen.
- Browser-Caching für CSS/JS auf v3.0.0 aktualisiert.

## Technische Sicherheit und Kompatibilität

Die Änderungen betreffen die Darstellung; API-Endpunkte, Minecraft-Steuerung, Spielerfunktionen, Monitoring-Datenspeicherung, Weltverwaltung und Systemdienste bleiben unverändert.

**Absichtlich erhalten:** Linux-Pfade unter `/opt/bedrock-control-pro` und `/etc/bedrock-control-pro`, die signierten ZIP-Namen `Bedrock-Control-PRO-vX.Y.Z-Release.zip`, das Ed25519-Manifest `bedrock-control-pro-release-v1` und der installer-Präfix. Das Upgrade von v2.9.0 muss ohne Neukonfiguration funktionieren.

## Vor einem Merge / Stable

1. GitHub Actions: PHP, JS, Syntax-/Paketbau und Branding-Regression.
2. Signiertes Testpaket aus dem v3-Branch auf vertrauenswürdigem Rechner erstellen.
3. Snapshot/Backup von `Minecraft-Test-2` vor dem Upgrade.
4. Upgrade 2.9.0 → 3.0.0 auf dem Testcontainer installieren.
5. Sichtprüfung von Login, Dashboard, Monitoring, Spielerverwaltung, Weltverwaltung, Add-ons und Mobilansicht; Bedrock-Dienst und Monitoring-Timer prüfen.
6. Erst danach Merge nach `main` und separates, frisches Stable-Release signieren.

**Produktionsinstallationen nicht direkt auf den Entwicklungsbranch aktualisieren.**
