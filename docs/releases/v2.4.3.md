# Bedrock Control PRO v2.4.3

**Status:** Auf einem frisch erstellten Debian-13-Testcontainer mit webbasiert nachinstalliertem Minecraft Bedrock Server erfolgreich erprobt.

## Highlights

- Installierbar auf einem Debian-13-System **ohne** vorhandenen Minecraft Bedrock Server.
- Minecraft-Installation und Serverkonfiguration über den geschützten Web-Einrichtungsassistenten.
- Vereinheitlichte systemd-Konfiguration für vorhandene Installationen und Minecraft-Neuinstallationen über den Assistenten.
- NetherNet-Watchdog wird beim Start eingebunden und prüft den konfigurierten Port aus `server.properties`.
- Bis zu 90 Sekunden Zeit für die NetherNet-Initialisierung; kontrollierte, begrenzte Neustartversuche.
- Gezielte ACL-Zugriffsrechte für `www-data`, um `server.properties` auch bei restriktiven Minecraft-Dateirechten lesen zu können.

## Bereits aus früheren Versionen enthalten

- Server-Dashboard, Start/Stop/Neustart, Live-Konsole und Logs
- Welten-, Add-on-, Backup- und Minecraft-Update-Verwaltung
- Automatische Installation der benötigten Debian-Abhängigkeiten
- Korrigierte PHP-Session-Prüfung und öffentliche Webdatei-Berechtigungen

## Installation

Das **Release-Asset** `bedrock-control-pro-v2.4.3-installer.zip` herunterladen. Das automatisch von GitHub angebotene „Source code“-ZIP ist **kein Ersatz** für das dokumentierte Release-Asset.

```bash
unzip bedrock-control-pro-v2.4.3-installer.zip
cd bedrock-control-pro-v2.4.3-installer
bash install.sh
```

Als `root` auf Debian 13 ausführen, danach `http://SERVER-IP:8088/` öffnen und gegebenenfalls Minecraft über den Web-Assistenten einrichten.

## Hinweise

- Das Setup benötigt Internetzugang und funktionierende APT-Paketquellen.
- Der Installer richtet **keine** Router-/Firewall-Portweiterleitung ein.
- Das Administrationspanel nur über vertrauenswürdiges Netz oder VPN erreichbar machen.
- Vor Updates und Änderungen Backups anlegen.
- Der automatische **Panel-Selbstupdate-Manager** ist erst für v2.5.0 geplant.
- Release-Asset erst als offiziell ansehen, nachdem es tatsächlich unter GitHub **Releases** veröffentlicht wurde.
